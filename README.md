# Evira - E-Commerce App

Flutter E-Commerce Project III (Ostad Module 29)

This project continues the e-commerce application from the class. It uses Provider, GoRouter, Dio, SharedPreferences and the same feature folders used in the class code.

## Main features

- Product catalog, categories, search and product details
- Add to cart, change quantity and remove items
- Guest cart saved on the device and cloud cart sync after login
- Login and profile with DummyJSON demo accounts
- Checkout form, address validation and order summary
- Cash on Delivery and class demonstration payment options
- Local order server integration, order history and order confirmation page
- Offline order saving when the class's local order server is not running
